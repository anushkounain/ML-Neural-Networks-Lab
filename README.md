## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/anushkounain/ML-Neural-Networks-Lab.git
cd ML-Neural-Networks-Lab
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run a programme

```bash
python programs/Q1.py
```

Replace `Q1.py` with the programme you want to execute.

### 4. Dataset Setup

The `datasets/` directory contains the datasets used by the practical programmes. Ensure the dataset paths in each Python script match the repository structure before running the code.
